# 🤖  AI — Autonomous Bangla Voice Assistant (আলী ও সম্পা)

**Stonic AI** হলো উইন্ডোজ (Windows 10/11) পিসির জন্য তৈরি একটি থ্রিডি ডট-ম্যাট্রিক্স ইন্টারফেস সমৃদ্ধ ডুয়াল-পারসোনা বাংলা এআই ভয়েস অ্যাসিস্ট্যান্ট (**আলী** ও **সম্পা**)। এটি সম্পূর্ণ বাংলা ভয়েস কমান্ডের মাধ্যমে পিসির যেকোনো ফাইল বা প্রজেক্ট ওপেন করা, কোডিং আইডিই (Antigravity / VS Code / Cursor)-তে স্বয়ংক্রিয়ভাবে `Submit` / `Accept` করা, ইউটিউব ও হোয়াটসঅ্যাপ নিয়ন্ত্রণ করা এবং কাজ শেষে নিজে থেকেই পিসি লক বা শাটডাউন করার মতো মাল্টিটাস্কিং করতে পারে।

> 🔒 **Identity Lock Notice:** এই প্রজেক্টটি ওপেন-সোর্স হলেও এর প্রধান এআই অ্যাসিস্ট্যান্টের নাম **‘আলী’ (Ali)** ক্রিপ্টোগ্রাফিক ও বাইটকোড সিকিউরিটির মাধ্যমে স্থায়ীভাবে লক করা। যে কেউ নতুন ফিচার যুক্ত করতে পারবেন, কিন্তু **‘আলী’** নামটি পরিবর্তন করা যাবে না।

## 🚀 ব্যবহারকারীরা কীভাবে পিসিতে ডাউনলোড ও ইনস্টল করবেন? (User Installation Guide)

### ১. পূর্বশর্ত (Prerequisites)
- **Windows 10 অথবা Windows 11** পিসি।
- পিসিতে **Python (3.10 থেকে 3.14)** ইনস্টল করা থাকতে হবে ([python.org](https://www.python.org/downloads/) থেকে ডাউনলোড করার সময় নিচে **`Add Python to PATH`** বক্সে অবশ্যই টিক দেবেন)।

---

### ২. পদ্ধতি A: মাত্র ১ ক্লিকে অটোমেটিক ইনস্টল ও চালু করা (সবচেয়ে সহজ)
১. এই গিটহাব পেজের ওপরে সবুজ **`<> Code`** বাটনে ক্লিক করে **`Download ZIP`** সিলেক্ট করুন।
২. ডাউনলোড হওয়া ZIP ফাইলটি মাউসের ডান বাটন চেপে **`Extract All...`** করে আনজিপ করুন।
৩. ফোল্ডারের ভেতরে থাকা **`install_and_run.bat`** ফাইলটিতে **Double-Click** করুন।
৪. এটি নিজে থেকেই সব প্রয়োজনীয় পাইথন প্যাকেজ ইনস্টল করবে এবং প্রথমবার **`.env`** ফাইলটি Notepad-এ ওপেন করবে। সেখানে আপনার ফ্রি [Groq API Key](https://console.groq.com/keys) অথবা [Gemini API Key](https://aistudio.google.com/app/apikey) বসিয়ে `Ctrl + S` দিয়ে সেভ করে Notepad বন্ধ করলেই **আলী ও সম্পা** আপনার ডিসপ্লেতে চালু হয়ে যাবে!

---

### ৩. পদ্ধতি B: টার্মিনাল / PowerShell দিয়ে ইনস্টল করা (ডেভেলপারদের জন্য)
আপনার পিসির **PowerShell** বা **Terminal** ওপেন করে নিচের কমান্ডগুলো পরপর রান করুন:

```powershell
# ১. গিটহাব থেকে প্রজেক্টটি ডাউনলোড (Clone) করুন
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME

# ২. প্রয়োজনীয় পাইথন প্যাকেজগুলো ইনস্টল করুন
py -m pip install -r requirements.txt

# ৩. API Key সেট করার জন্য .env ফাইল তৈরি করুন
copy .env.example .env
notepad .env

# ৪. অ্যাপটি চালু করুন
py main.py
```

---

### ৪. কীভাবে নিজের পিসিতে `.exe` সফটওয়্যার ফাইল তৈরি করবেন? (Build `.exe`)
আপনি যদি টার্মিনাল ছাড়া সরাসরি ডেক্সটপ অ্যাপ (`.exe`) হিসেবে ব্যবহার করতে চান, তবে ওই ফোল্ডারের টার্মিনালে নিচের কমান্ডটি দিন:

```powershell
py -m PyInstaller --noconfirm --onefile --windowed --uac-admin --name "Stonic_AI" --add-data "ui;ui" --add-data "core;core" --add-data "agents;agents" --hidden-import=edge_tts --hidden-import=speech_recognition --hidden-import=pyttsx3 --hidden-import=pyautogui --hidden-import=pyperclip --hidden-import=psutil --hidden-import=dotenv --hidden-import=requests main.py
```
বিল্ড শেষ হলে `dist` ফোল্ডারের ভেতরে **`Stonic_AI.exe`** ফাইলটি পেয়ে যাবেন!

## 🎙️ জনপ্রিয় ভয়েস কমান্ড তালিকা (Voice Commands)
- **কথা বলা:** `"হ্যালো আলী, কেমন আছো?"` বা `"সম্পা, আমাকে একটা বুদ্ধি দাও"`
- **ফাইল বা প্রজেক্ট ওপেন করা:** `"আলী, school.html ফাইলটা ওপেন করো"` / `"আলী, school sms প্রজেক্টটা ইন্টিগ্রাভিটিতে ওপেন করো"`
- **অটো-সাবমিট মোড (বাইরে যাওয়ার সময়):** `"আলী, আমি বাইরে যাচ্ছি, অটো সাবমিট চালু করো এবং প্রজেক্ট শেষ হলে কম্পিউটার লক করে রাখবে"`
- **সিঙ্গেল সাবমিট/এক্সেপ্ট:** `"আলী, সাবমিট করো"` / `"এক্সেপ্ট করো"`
- **ব্যাকগ্রাউন্ড ও সুইচ কন্ট্রোল:** `"আলী, ব্যাকগ্রাউন্ডে যাও"` (ডিসপ্লেতে ফেরত আনতে আবার `"আলী"` বা `"সম্পা"` বলে ডাক দিন)।
